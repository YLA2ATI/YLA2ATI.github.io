How to Connect

Pick your platform below and follow one of the methods.

⚠️ Using a Legacy Account is recommended (GrowID). Using Gmail sign-in? Join the Discord and open a ticket for help as it needs one-time manual verification.

🖥️ PC Setup

1

⚡ One-Click Setup Recommended

  1. ⬇️ Download PowerKuy-Setup.bat. If your browser warns about the file, choose Keep.
  2. Run it — double-click the file and click Yes on the Windows prompt. (If a blue "Windows protected your PC" box appears, click More info → Run anyway.)
  3. It sets everything up automatically — wait for "PowerKuy connected successfully!"
  4. Relaunch Growtopia — log out, fully close it, then reopen and log in. 🎉

One file does it all (certificate + server redirect) — no antivirus steps needed. Run it any time to reconnect.

📱 Android Setup

1

⚡ Modded APK Recommended

  1. Uninstall your current Growtopia app.
  2. Download & install the PowerKuy client: Growtopia.apk. Allow installs from unknown sources if prompted.
  3. Open the app, log in, and enjoy! ▶️

🍎 iOS Setup

Two quick parts — do both, in order. Keep Growtopia closed during setup.

1

📜 Install the Certificate Do this first

  1. ⬇️ Download the certificate: PowerKuyRootCA.crt. If Profile Downloaded doesn't appear, open Files and tap the downloaded certificate once.
  2. ⚙️ Open Settings → General → VPN & Device Management.
  3. Tap PowerKuy Root CA, then Install. Enter your passcode if asked and confirm until Profile Installed appears.
  4. ⚙️ Go to Settings → General → About → Certificate Trust Settings.
  5. 🛡️ Turn on Full Trust for PowerKuy Root CA and tap Continue.

🎥 Watch the certificate steps — 1-min video

Certificate installed? Full Trust must also be ON. Then continue to Part 2 below.

2

📲 Connect with Surge 5

  1. ⬇️ Install Surge 5 from the App Store, then open it.
  2. In Surge, choose import a configuration from URL and paste this profile address: 
    https://powerkuy.com/ios.config
  3. 🌐 Select the imported profile and start Surge. Allow the VPN configuration if iOS asks. Keep Surge running while you play.
  4. ▶️ Open Growtopia → log out of your GrowID → log back in — you're in! 🎉
